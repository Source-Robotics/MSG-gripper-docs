# First setup

From a mounted and cabled gripper to one that opens and closes on command. Motor GUI in the browser is the usual
tool for it; every step also gives the Python call and the UART command.

1. [Motor GUI](motor-gui.md): the browser, the CANvas adapter, connecting to the gripper, the gripper panel.
2. [Calibrate, activate, move](first-moves.md): the three things every session starts with, and the first grip.
3. [Driver configuration for a self-built gripper](driver-configuration.md): what a bought gripper already has
   and a self-built one needs: the driver's motor calibration, gripper mode, the thermistor.

A gripper that has been through these pages is ready for [Operation](../06-operation/index.md).
