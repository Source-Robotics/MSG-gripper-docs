The header has four tabs. **MSG Gripper Manual** is the document you read from the start: safety,
technical data, installation, the first setup, operation and firmware, in numbered chapters. **API
reference** lists the gripper's CAN messages and UART commands for the firmware release this site describes, with
the status bits and the Python library's calls, and is where you look things up; the driver's complete reference
is on the STEPFOC site. **Guides** are worked examples, such as teleoperation. **Support** says where
to get help and how to report a problem.

The whole site describes one gripper release, with the driver firmware it runs named on the landing page. The
dropdown next to the site name switches between gripper releases, and a page from an older release says so in a
bar at the top. The repository card on the right
of the header opens the product repository; every page ends with a link to edit it and one to report a problem
with it.
