*[FOC]: Field-Oriented Control: the motor's current is controlled as a vector relative to the rotor position
*[CAN]: Controller Area Network, the bus between the robot or the PC and the gripper
*[UART]: the serial port of the driver inside the gripper, 3.3 V, 256000 baud
*[PWM]: Pulse-Width Modulation
*[EEPROM]: the non-volatile memory on the driver that holds its configuration
*[RTR]: Remote Transmission Request, the CAN frame type that asks a node to send data
*[BOM]: Bill Of Materials, the list of parts to buy
*[STEP]: the CAD exchange format the gripper's parts are published in
*[3MF]: the print file format of the ready-to-slice parts
*[TPU]: thermoplastic polyurethane, the soft filament of the jaw pads
*[PETG]: the filament the body is printed in
*[URDF]: Unified Robot Description Format, the robot description used by ROS 2
*[MJCF]: MuJoCo's robot description format
*[LED]: Light-Emitting Diode
*[NTC]: Negative Temperature Coefficient thermistor, the temperature sensor in the windings
*[DP]: Diametral Pitch, the tooth size of the pinion and the racks
