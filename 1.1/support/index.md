# Getting help

- **Questions and discussion**: the [Source Robotics Discord](https://discord.gg/prjUvjmGpZ).
- **A problem with the gripper's hardware or its files**: an issue in the
  [product repository](https://github.com/Source-Robotics/MSG-compliant-AI-stepper-gripper/issues); see
  [Report a problem](https://docs.source-robotics.com/MSG-gripper-docs/1.1/support/report-a-problem/) for what to include.
- **A problem with the firmware**: an issue in the [driver's repository](https://github.com/Source-Robotics/STEPFOC-stepper-controller/issues);
  with the Python library, in [Spectral-BLDC-Python](https://github.com/Source-Robotics/Spectral-BLDC-Python/issues);
  with the ROS 2 driver, in [its repository](https://github.com/Source-Robotics/source_robotics_msg_gripper_ros2/issues).
- **A mistake on a page of this site**: every page ends with a link to edit it and one to report it; see
  [Contributing](https://docs.source-robotics.com/MSG-gripper-docs/1.1/support/contributing/).
- **Orders and hardware**: [source-robotics.com](https://source-robotics.com/).

Before you ask, [Troubleshooting](https://docs.source-robotics.com/MSG-gripper-docs/1.1/09-troubleshooting/) goes through the common symptoms, and the gripper's
status tells most of what anyone will ask you for.
