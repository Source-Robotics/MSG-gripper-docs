# First setup

For the complete bench procedure, use the [one-page quick start](https://docs.source-robotics.com/MSG-gripper-docs/1.1/quick-start/).

From a mounted and cabled gripper to one that opens and closes on command. Motor GUI in the browser is the usual
tool for it; every step also gives the Python call and the UART command.

1. [Motor GUI](https://docs.source-robotics.com/MSG-gripper-docs/1.1/05-setup/motor-gui/): the browser, the CANvas adapter, connecting to the gripper, the gripper panel.
2. [Calibrate, activate, move](https://docs.source-robotics.com/MSG-gripper-docs/1.1/05-setup/first-moves/): the three things every session starts with, and the first grip.

A self-built gripper first needs its driver set up, which a bought one already has: [Driver setup and first run](https://docs.source-robotics.com/MSG-gripper-docs/1.1/build/first-run/)
in the build guide.

A gripper that has been through these pages is ready for [Operation](https://docs.source-robotics.com/MSG-gripper-docs/1.1/06-operation/).
